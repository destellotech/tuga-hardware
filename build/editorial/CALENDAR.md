# Blog calendar

One guide a week. A scheduled cloud agent takes the **first row with status
`todo`**, writes it, opens a PR and sets the row to `pr`. When the PR is
merged, the row counts as published. Reorder, edit or delete rows freely; set
a row to `skip` to veto it.

Status: `todo` → `pr` → `done` (or `skip`).

Before writing, check the topic does not overlap an existing post in
`build/content/blog/`. If it does, sharpen the angle rather than repeat it.
